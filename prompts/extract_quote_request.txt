This email was classified as a quote request: someone asking for a price or quotation for specific work, products or services. Extract these fields:

- client_name: the name of the person asking. null if not given.
- client_company: their company or organisation. null if not given.
- client_email: their email address. Use the From line address unless the email body clearly gives a different contact address for the same person. null if neither is available.
- items: a list with one entry per product or service they want quoted. Each entry has:
  - description: the product or service, copied in the language it was written, not translated.
  - quantity: a plain number such as 500, or null if no quantity is stated. Convert Arabic-Indic digits (٠١٢٣٤٥٦٧٨٩) to normal digits.
  - unit: the unit if one is stated (for example "pcs", "hours", "pages"), otherwise null.
  If the email names no specific product or service, use an empty list []. Never invent an item.
- deadline_text: the deadline exactly as written. null if there is none.
- deadline_date: the deadline as YYYY-MM-DD, only when it can be worked out for certain. Use the Received line for the year and for words like "tomorrow" or "next Friday". null if the date is unclear, incomplete or missing.
- notes: other details that matter for the quote (delivery place, size, colours, conditions) in one or two English sentences. null if there are none. Never longer than 500 characters.
