- name: the person's name as written. null if not given.

- company: the company or organisation they represent. null if not given.
- phone: a phone number exactly as written, including any country code. null if not given.
- request_summary: one or two English sentences saying what they want from the business. Never null, never longer than 500 characters.
- budget_if_mentioned: any budget the sender states, copied as written with its currency, for example "around 2000 EGP". null if none is stated.
